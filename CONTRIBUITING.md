# Manual de Contribuição

## 🛠️ 1. Contribuição de Código (Desenvolvimento)
Nossa plataforma utiliza a licença **AGPLv3**. Ao contribuir, você concorda em manter o código aberto.

### Como começar:
1. **Faça um Fork** do repositório.
2. **Crie uma Branch** seguindo nossos padrões abaixo.
3. **Reporte bugs ou sugira melhorias** através das Issues antes de começar grandes mudanças.
4. **Submeta um Pull Request (PR)** apenas após garantir que o código foi testado localmente.

### Padrões de Branch:
* **Correção de Bug:** `fix/codelevel-[numero-issue]` (ex: `fix/codelevel-123`)
* **Nova Funcionalidade:** `feature/codelevel-[numero-issue]` (ex: `feature/codelevel-124`)
* **Melhorias/Refatoração:** `improvement/codelevel-[numero-issue]` (ex: `improvement/codelevel-132`)

> **Nota:** Para manter o repositório limpo, as branches de trabalho serão removidas após o Merge.

## 📚 2. Contribuição de Conteúdo (Lecionar Cursos)
Todo o conteúdo didático é distribuído sob a licença **CC BY-SA 4.0**.

### Como criar um curso:
1. **Consulte o quadro** de "Cursos Necessários" [Link]().
2. **Submeta uma ementa:** Abra uma Issue com a proposta de módulos e aulas para alinhamento pedagógico.
3. **Envio:** O conteúdo pode ser enviado via Pull Request (arquivos Markdown/Links) ou via painel do tutor na versão Beta.

> **Nota:** 
> Ao enviar um curso via embedding do YouTube, o colaborador declara ser o autor do conteúdo ou possuir autorização para tal, mantendo os direitos autorais conforme as normas da plataforma de origem. O material de apoio (textos, exercícios, ementas) submetido a este repositório passa a seguir a licença CC BY-SA 4.0.

### Padrões de Qualidade:
* **Áudio/Vídeo:** Som claro, sem ruídos de fundo e boa iluminação.
* **Didática:** Exemplos práticos e exercícios obrigatórios ao final de cada módulo.
* **Linguagem:** Inclusiva, respeitosa e acessível a iniciantes.
